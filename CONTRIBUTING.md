# Contributing to FarmPulse AI

We welcome contributions to FarmPulse AI. To contribute:

1. Fork the repository on GitHub.
2. Create your feature branch (`git checkout -b feature/new-capability`).
3. Commit your changes with clear, descriptive commit messages.
4. Ensure all unit and integration tests pass:
   ```bash
   pytest -v tests/
   ```
5. Ensure the frontend builds cleanly without errors:
   ```bash
   cd frontend && npm run build
   ```
6. Push to the branch and open a Pull Request.
